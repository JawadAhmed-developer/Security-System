This is a menu-driven security system developed in 8086 Assembly Language using EMU8086.
It allows users to log in with a PIN, arm/disarm the system, simulate intrusions, and trigger alarm alerts.
The project demonstrates keyboard input, memory usage, registers, conditional jumps, loops, and DOS interrupts in a practical scenario.

✅ Features

PIN Authentication

Arm/Disarm System

Menu Interface

Intruder Detection Simulation

Alarm Notification

Exit Option

🛠 Tools Used

8086 Assembly Language

EMU8086 Emulator

DOS Interrupts (INT 21H)

MASM/TASM

▶️ How to Run

Open EMU8086

Load SecuritySystem.asm

Compile and run

Enter PIN and navigate menu options
