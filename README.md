## 📌 Project Description

The Smart Security Alert System is a menu-driven security application developed using 8086 Assembly Language.  
It simulates a basic home/office security system that allows user authentication, system arming/disarming, and intruder detection with alarm alerts.

The project demonstrates low-level programming concepts such as registers, memory handling, interrupts, conditional jumps, and arithmetic/logical instructions.

---

## 🎯 Features

- PIN-based Authentication System
- Arm Security System
- Disarm Security System
- Intruder Detection Simulation
- Alarm/Alert Message
- Menu Driven Interface
- Keyboard Input Handling
- Conditional Logic Processing
- Loop-based Monitoring System
- Exit Option
